# 006 — 보안 때문에 이미지를 다시 굽는다 (pip 26.1 · 베이스 갱신) · v0.3.1

2026-10-23 · `work/20261023-paleoadmin` · paleoadmin

## 왜

기능 변경이 없는 판이다. 2026-10 에 pip·uv·PHP 의 취약점이 잇달아 나와 서버와
컨테이너를 점검했고(같은 날 서버를 Ubuntu 26.04 로 올린 뒤), 이 저장소의
이미지에 걸리는 것은 **pip** 하나였다.

| 무엇 | 취약점 | 이 저장소 |
|---|---|---|
| pip | CVE-2026-6357 (설치 직후 자기 갱신 확인이 방금 깐 wheel 의 모듈을 임포트해 코드가 돈다) · CVE-2026-3219 (tar 이면서 zip 인 파일을 zip 으로 읽어 다른 파일이 깔린다) · CVE-2026-8643 (entry point 이름으로 scripts 디렉토리 밖에 쓴다) · CVE-2026-13346 (두 번 인코딩한 URL 로 인덱스가 임의 경로에 쓴다) · CVE-2026-1703 (wheel 을 설치 디렉토리 밖 형제 경로에 푼다). 대부분 **26.1 미만** | 뷰어 이미지 **25.0.1**. 걸린다 |
| uv | CVE-2026-114109 (0.11.15 에서 고침) · CVE-2026-114110 (0.11.6) | 이미지·CI 어디에도 uv 가 없다. 안 걸린다 |
| PHP | CVE-2026-109618 · 109619 ("PHP2Shell", 원격 코드 실행, 실제 공격 있음) | PHP 가 없다. 안 걸린다 |

pip 의 결함은 전부 **악성 패키지나 인덱스로 설치할 때** 일어난다. 컨테이너는
돌면서 pip 을 안 부르므로 운영 중인 이미지가 바로 위험한 것은 아니다 — 위험한
자리는 **이미지를 굽는 순간**이다. 그래도 고쳐 둔다: 굽는 자리가 CI 와 이 서버
둘이고, 고정(`==`)하지 않은 간접 의존이 그때마다 새로 받힌다.

**pip 은 베이스 이미지를 새로 받아도 안 올라간다.** `python:3.12-slim` 의 pip 은
그 파이썬 판(3.12.x)이 묶어 낸 것이라 보안 갱신 주기만 따라간다 — 지금 받아도
25.0.1 이다. 그래서 Dockerfile 에서 직접 올린다.

다시 굽는 김에 **베이스 이미지(Debian 13 · 파이썬 3.12) 의 보안 갱신도 같이
들어온다** — v0.3.0 은 2026-09-21 에 받은 베이스다.

## 무엇을

- `deploy/Dockerfile.base` — `pip install -r` 앞에 `pip install --upgrade "pip>=26.1"`
- `deploy/Dockerfile.pipeline` — 같은 줄
- 판은 PATCH 만 올린다: `v0.3.0` → **`v0.3.1`** (사용자 방침 · 기능 변경 없음)
- `v0.3.0` 뒤에 쌓인 004(옛 이미지 정리)·005(`deploy.sh` 를 `main()` 으로 감싸기)도
  이 판에 실린다 — 둘 다 아직 판으로 안 나갔다

## 버린 것

- **파이프라인 이미지는 이번에 굽지 않는다.** Dockerfile 만 고쳐 두고
  `PIPELINE_TAG=v0.1.0` 을 그대로 둔다. Docker 의 데이터 디렉토리가 `/data3/docker`
  (sdc) 인데, 그 디스크가 지금 재할당 섹터 6,136 · 대기 섹터 144 로 상태가 나쁘고
  SMR 이라 대용량 쓰기가 몰리면 수 MB/s 로 떨어진다 — 2026-10-23 오전에 다른
  복사가 그렇게 몰려 dockerd 가 통째로 멈췄다. 파이프라인 이미지는 7 GB 다.
  **디스크를 바꾼 뒤 굽는다.** 그때 이 줄이 이미 들어 있으니 다시 고칠 것은 없다
- pip 판을 `==` 로 박기 — 다음 보안판을 받으려면 또 고쳐야 한다. 하한만 둔다
- 호스트 venv(`~/venv/ForGIA`)는 이 판과 따로 다시 만들었다 — Ubuntu 26.04 에
  파이썬 3.12 가 없어져 venv 가 깨졌기 때문이고(백업·NAS 동기화 cron 이 실패하고
  있었다), uv 가 받은 3.12.15 로 같은 판의 패키지를 다시 깔았다. pip 도 그때 26.2 가 됐다
